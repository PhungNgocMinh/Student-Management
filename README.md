# Student-Management
Homework for Programming on Windows module

This repository was created for the homework of the module "Programming on Windows" at Ho Chi Minh city University of Education (HCMUE) on September 24th, 2026.
The program needed to meet these requirements:
  1. **Enter quantity**: Enter the number of students $n$ in the class ($n > 0$).
  2. **Enter information**: Loop through to enter the full name and corresponding score for each student.
  3. **Calculate average score**: Calculate the overall average score of all students in the class.
  4. **Find the highest score**: Find the highest score level in the class.
  5. **Count the number of passing students**: Count the number of students with a score $\ge 5.0$.
  6. **Print student list**: Display a neatly formatted table containing the names and scores of the entire class.
